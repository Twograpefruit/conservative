# Conser desktop app (Tauri + WebView2)

Builds a native Windows window (no browser tab) that starts the local BFF for you.

## Result

`npm run desktop:build` produces:

```
apps/desktop/src-tauri/target/release/bundle/nsis/Conser_0.1.0_x64-setup.exe
```

The installer contains:

- the Tauri/WebView2 shell (`opencode-gui-desktop.exe`, renamed **Conser** in setup);
- a Node runtime sidecar (`node.exe`), so the target machine does not need Node installed;
- the BFF bundle + production dependencies under `server/`;
- the built SPA under `gui/`.

The shell starts the BFF on launch, waits for `/api/health`, opens the window, and kills
the BFF when the app exits. If a Conser BFF is already running, it is reused.

## Prerequisites

- Windows 10/11 with WebView2 (preinstalled on current Windows).
- Rust MSVC toolchain (`rustup default stable-x86_64-pc-windows-msvc`).
- Node.js 20+ for building.
- opencode installed locally, **or** configure WSL/remote under
  **Settings → Status → 上游连接** after first launch.

To bundle opencode into the installer as well:

```powershell
$env:OCG_BUNDLE_OPENCODE = '1'
npm run desktop:build
```

This adds ~250 MB to the app because `opencode.exe` is copied into `server/opencode/`.

## Commands

```powershell
# stage server/gui/node resources only
npm run desktop:prepare

# build SPA + BFF, stage resources, compile Rust, build NSIS installer
npm run desktop:build

# run the desktop shell in development
npm run desktop:dev
```

## Ports

The BFF prefers `4310`; if that port is busy it picks the next free port and writes it to
`%LOCALAPPDATA%\opencode-gui\runtime.json`. The desktop shell reads that file and opens the
correct URL, so another local service on 4310 does not break the app.

BFF log when launched by the desktop shell:

```
%LOCALAPPDATA%\opencode-gui\logs\desktop-bff.log
```

## Notes

- The app uses Windows WebView2, not a full browser. It is a normal native window.
- Code signing is not configured. Windows SmartScreen may warn on first run; use
  `signtool` with your certificate before distribution if needed.
- Resources are gitignored: `src-tauri/server`, `src-tauri/gui`, `src-tauri/binaries`.
- The installer is generated by Tauri (NSIS); `.msi` can be enabled by adding `"msi"`
  to `bundle.targets`.
